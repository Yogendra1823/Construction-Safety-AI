## 📌 Executive Overview

Modern construction mega-projects face escalating challenges including unexpected cost overruns, safety compliance breaches, schedule slippages, and fragmented resource tracking.

**Agentic AI for Safety Monitoring with Construction Risk Analytics** is an end-to-end enterprise solution that unifies site surveillance, predictive risk analytics, workforce management, and automated financial estimation into a centralized, intelligent command center.

The application adheres to four strategic operational pillars:
```
  [ PLAN ] ───► [ EXECUTE ] ───► [ MONITOR ] ───► [ OPTIMIZE ]
     │               │                │               │
     ▼               ▼                ▼               ▼
 Client Brief     Workforce &      Safety Logs &    AI Predictive
 Cost Analytics   BOQ Tracking    KPI Dashboards    Risk Overrun
```

## ✨ Key Platform Capabilities

### 🦺 1. Real-Time Safety Monitoring & Incident Tracking
- **PPE & Site Checklist Verification**: Interactive safety compliance checklists with real-time score updates.
- **Incident Lifecycle Management**: Full resolution workflow for site incidents (Open → Investigating → Resolved).
- **Emergency Action Directory**: Instant site escalation contact details.

### 🧠 2. Composite AI Risk Analytics & Forecasting
- **Multi-Factor Risk Scoring Engine**: Evaluates budget variance, delay probabilities, safety incident history, and workforce availability into a composite 0–100 Risk Score.
- **Delay Risk "What-If" Calculator**: Interactive scenario simulator predicting delay impact based on headcount adjustments and material delivery schedules.
- **AI Narrative Risk Summaries**: Grounded explanatory narratives generated by a local LLM engine.

### 📋 3. Client Requirement Analyzer & Smart Area Planner
- **Natural Language Brief Processing**: Translates unstructured client project briefs into structural specifications, budget bounds, and material breakdowns.
- **Smart Area Planner**: Calculates total built-up area, estimated RCC slab volume, structural steel requirements, and finish estimates.

### 🧾 4. Materials Management & Automated BOQ Generator
- **One-Click BOQ Generation**: Generates comprehensive Bills of Quantities (BOQ) with unit costs and total estimates.
- **Export Pipelines**: Export full reports to production-ready **PDF** and **Excel (.xlsx)** formats.
- **Inventory & Reorder Alerts**: Inline stock tracking with automatic low-stock notifications.

### 💰 5. Budget, Workforce & Fleet Management
- **Cost Variance Analysis**: Track allocated vs. actual project expenditures.
- **Workforce Attendance Roster**: Manage daily worker attendance, trade specializations, and daily wage payouts.
- **Equipment Logistics**: Directly editable equipment status, fuel tracking, and preventative maintenance schedules.

### 🤖 6. Grounded Local AI Assistant (Ollama + Gemma 3 1B)
- **Zero-Hallucination Guardrails**: Fast Python pre-filtering intercepts off-topic queries *before* LLM execution.
- **Direct Database Grounding**: Answers natural language queries over real-time database context (project status, cement stock, budget metrics, safety incidents).
- **Floating Chat Widget**: Persistent AI assistant popover available on every page.

## ⚡ Quick Start Guide

### Option 1: Automated Launch (Recommended)

Run the single-command automation script which configures the environment, database, and seeds demo data automatically:

```bash
python automate.py
```

### Option 2: Manual Setup

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/<YOUR_USERNAME>/Agentic-AI-Safety-Construction-Risk.git
   cd Agentic-AI-Safety-Construction-Risk
   ```

2. **Set Up Virtual Environment**:
   ```bash
   python -m venv venv
   # On Windows PowerShell:
   .\venv\Scripts\activate
   # On Linux/macOS:
   source venv/bin/activate
   ```

3. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Configure Environment Variables**:
   ```bash
   cp .env.example .env
   ```

5. **Initialize Database & Seed Data**:
   ```bash
   python -c "from database.seed import seed_demo_data; seed_demo_data()"
   ```

6. **Launch Application**:
   ```bash
   streamlit run app.py
   ```
